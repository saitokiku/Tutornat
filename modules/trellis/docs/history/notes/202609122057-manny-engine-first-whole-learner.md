# Preserve the attempts; build the engine first

Email received 2026-09-12 20:45 CDT; captured 2026-09-12 20:57 CDT. Manny:

> "use the Kaizenedu repo and we test everything on the same website and we’ll deploy later"

> "let’s start with the engine final all the pid loops and algorithms for student and teaching tightened and verified and we will then create the front end architecture then the backend architecture … lay out the plans first"

> "import syllabus too or all previous homework's with corrections and school practice other teacher docs etc to really build a better picture with the students dataset"

> "build the whole thing all ages all at once a good interactive Ui and homework management abilities with AI and a great teaching canvas that actually works"

He wants both attempts preserved for reuse; a complete learning system built incrementally with his teaching judgment, grilling and research. Community patterns should eventually reveal gaps deep enough to investigate school-level issues. That ambition does not establish school causation or authorize disclosure of children's records.

All school ages including younger siblings are already accepted in ADR-0045. Adult accounts remain an unanswered extension. Literal PID control is a candidate interpretation, not an accepted or validated teaching algorithm.

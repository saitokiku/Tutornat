# Nikola and Rosalind: both conflict-found

Astra, codex/gpt-6-astra, 2026-09-17 00:06–00:17 CDT, 10m48s inside a 20-minute box. Eighteen
live USPTO records TSDR-checked in classes 9/41/42, positive control returned, every query HTTP 200.

**Nikola.** Grassroot already markets a **"Nikola Tesla AI tutor"** in a US-facing education
product, including test prep — the same honoree, the same job. A registered Tesla education
electronics kit sits beside it. Nikola Corporation's vehicle marks are remote and are *not* the
reason. "Nikola Tutor" / "Ask Nikola" returned zero exact hits, which does not cure the overlap.

**Rosalind.** rosalind.info is an established education platform (UC San Diego link); OpenAI and
LiteFold use Rosalind for scientific AI; Onramp and DNA Labs hold relevant live federal records.
Different audiences reduce direct overlap but do not make a clean persona name.

"Conflict-found" means a concrete related use warrants counsel before adoption — not that
infringement was established, and not a prohibition on every character use. A character name can
identify a character or identify the source of services; that is use-dependent (TMEP §1301.02(b)),
so how the persona is introduced in-product matters as much as the word.

Astra's recommendation: hold both, send the evidence pack to counsel for a narrow opinion on the
actual in-product persona and marketing. The company brand is a separate, still-blocked question
([202609162351-both-chosen-names-are-blocked-in-education](202609162351-both-chosen-names-are-blocked-in-education.md)).

**Wording rule for any story we tell:** Rosalind Franklin *helped reveal DNA's structure* — she did
not "find DNA"; Raymond Gosling took Photo 51 under her supervision. Tesla did not invent electricity
or work alone. Manny's shorthand is fine in a text; it is not fine on a screen a child reads.

Next: a screened shortlist of other people worth honoring is running (`16-persona-name-shortlist`),
so his choice is a menu, not an A/B between two conflicts.

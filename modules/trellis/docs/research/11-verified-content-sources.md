# RO-11 — Reviewed content sources for Algebra 1 readiness

Researched 2026-09-12. Scope: fractions → ratios/proportional reasoning → linear equations, approximately US grades 6–9, for Kaizen’s paid $49/month service, including possible learners under 13. Primary-source desk research; no vendors contacted, accounts created, API keys requested, contracts accepted, or learner data transmitted.

**Recommendation: acquire Oak National Academy’s current OGL-licensed maths content first; use Illustrative Mathematics first edition at Kendall Hunt where a US-aligned sequence or additional practice is needed. Both have a $0 content-licence route; Oak’s API is also free.** Oak has the clearest documented human checks and structured quiz-answer access. IM first edition has unusually clear commercial-use permission and a US middle-school curriculum, but teacher solutions require registration. These are acquisition recommendations, not a claim that an imported bank is ready for learners. [Oak terms](https://www.thenational.academy/legal/terms-and-conditions-api-version), [Oak API and price](https://open-api.thenational.academy/docs/about-oaks-api/api-overview), [IM edition-specific terms §7](https://illustrativemathematics.org/terms-of-use/).

**K7 is reduced, not eliminated.** The supplied brief says the inherited bank has 118 items and none with both review fields populated. That count was not independently re-audited here. Publisher review provides provenance and reduces original authoring/checking work; it does not populate Kaizen’s review fields or supersede SPEC §4. The local SPEC’s human-loop and release requirements were also read. A designated human must still approve each selected item before release; checking its final Kaizen rendering and scoring is the recommended acceptance method. No evidence found establishes a source whose adoption alone satisfies that gate.

## The remaining human gate and key boundary

1. **Select a small, coherent launch set.** A teacher/content reviewer chooses the skill progression and source items; importing an entire large bank would recreate the review backlog. The first reviewed source pool need not contain all 118 inherited items or reproduce them one for one. Reserve separate, unfamiliar items/parallel forms for independent checks; practice items and their numerically tweaked clones do not establish transfer or form equivalence. Source review supports item quality, not Kaizen’s mastery thresholds.
2. **Record provenance separately from Kaizen approval.** For each selected item, retain source URL, exact edition/file, source item identifier, licence/exceptions and attribution. Attach publisher-review evidence as provenance. The actual Kaizen reviewer records their own review identity/date and the required fields after checking the final item; do not substitute the publisher’s name or publication date into unperformed approval work.
3. **Approve the transformed item and scorer.** A human checks displayed maths/diagrams, ambiguity, distractors, correct answer, equivalent fractions/forms, tolerances/units, partial credit where used, reading level and prerequisite mapping. Translation, numerical variants or AI rewrites create changed items requiring another review. Curriculum-level review is not psychometric validation of a new mastery threshold.
4. **Keep all answer-bearing content out of client and tutor payloads.** Import into separate question/asset and answer/rubric records; use an explicit field allowlist for delivery. Do not place teacher PDFs, solution text, correct-option flags, distractor rationales or full source JSON in tutoring retrieval. Public-key availability elsewhere does not justify sending keys from Kaizen. Inspect actual learner and tutor payloads before approval; vendor UI settings alone are insufficient.
5. **Preserve rights and attribution.** OGL and CC BY permit commercial reuse without share-alike. A CC BY-NC or BY-NC-SA download does not become commercially usable because access was free or the app has educational goals. For SA content, obligations attach to licensed adaptations; it is inaccurate to claim that all unrelated proprietary app code automatically becomes open source. [OGL](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Under-13 considerations in this report distinguish **copyright permission to serve local content** from **terms and privacy obligations for a hosted student service**. Fetching licensed files on an adult-operated server can avoid creating third-party learner accounts; that is an architectural option, not a finding that Kaizen’s own child-data launch gates are satisfied. Oak’s API documentation mentions usage-data requests, so clarify the intended aggregate reporting during authorized onboarding rather than assume there is no reporting relationship. [Oak API overview](https://open-api.thenational.academy/docs/about-oaks-api/api-overview), [Oak privacy](https://www.thenational.academy/legal/privacy-policy).

## Evidence limits

- Public primary sources were read for each named candidate; publisher claims are identified as such. “Reviewed” is not inferred from popularity, open licensing, author credentials alone, state alignment, or an efficacy study of the platform.
- Licence and pricing links are beside the claims. Where a commercial price, relevant agreement, item count, API or export right was not established, it remains explicitly unverified. A quotation of restrictive terms is not a substitute for the actual contract that would govern a future purchase.
- Public source samples and PDF/text evidence were inspected. No authenticated bank export, operational scoring integration or learner-ready item set was produced. This report does not assert a measured reduction in review hours.
- Edition differences are material: IM first edition versus v.360/task site; OUR first/second versus third edition and excluded assessments; legacy MVP versus later OUR derivatives; current OpenStax NC-SA versus historically reported BY editions; original Eureka versus Math². Aggregator labels cannot resolve those differences.
- A national test’s development process supports the original instrument; modified subsets do not inherit its norms. A platform’s open-source software licence says nothing about the licence or review status of content loaded into it.

**Decision supported:** choose an openly licensed, publisher-reviewed source spine and retain a named human for final import acceptance. Oak plus selectively used IM first edition is the fastest supported acquisition path at $0 verified content/API fees; a zero-human-review launch is not supported by the current SPEC or the evidence.

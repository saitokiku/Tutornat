## Identity

`CLAUDE.md:1-5`: "Natural Tutor is a voice-first 1:1 AI tutor with a face, built on a fork of OpenMAIC (MIT). `docs/SPEC.md` is the contract; decisions D1–D16 there are made." The README opens with the product promise: "A voice-first 1:1 AI tutor for one child at a time. It talks, listens, draws on a whiteboard, checks whether the learner actually understood, remembers what was hard, and tells a parent what changed — without ever grading its own help as mastery" (`README.md:3`).

The spec header names the company and the clock: "Natural Tutor (working name) — a 1:1, voice-first AI tutor SaaS built on OpenMAIC · **Company:** Kaizen AI · **Owner:** Manny · **Date:** 2026-09-03" with Gate 1 at Day 14 (2026-09-17), Gate 2 at Day 21–30 for under-13 profiles, Gate 3 at weeks 6–10 for ages 4–8 (`docs/SPEC.md:1-5`). `docs/PLAN.md:3` records a hard external date: "the YC deadline is 2026-11-02 20:00 PT."

Five invariants are stated as tests, not aspirations (`CLAUDE.md:11`): no cross-account reads; audio bytes never written to disk, database, storage, logs or error reports; no camera frame, landmark, embedding or template leaves the browser; every session has a cost ceiling and every learner a daily cap; provider keys are server-side only and absent from every client bundle.

Upstream's own README is Chinese (`README-zh.md`, 39 KB) and the English upstream README is preserved at `docs/OPENMAIC-README.md` (1,041 lines). The repo's own README replaced it on main on 2026-09-05 (`8dff818` "Take the face off the landing page, write our own README, credit the work").

## What is actually built

**Product API (35 routes), under the route groups** so middleware can gate them: 27 at `app/(learner)/api/tutor/*` — `turn` (SSE), `tts`, `asr`, `attention`, `check`, `session`, `wrap`, `progress`, `coursework`, `problem-extract`, `flag`, `error-report`, `support`, `health`, `email/unsubscribe`, `cron/weekly-email`, and 9 auth routes (sign-up, sign-in, sign-out, me, learner, teen-sign-in, teen-invite, parent-invite, parent-invite/accept, password-reset ×2) — plus 8 at `app/(parent)/api/parent/*` (billing, billing/webhook, consent, data, learners, report, settings, transcripts).

**Upstream API (69 routes) at `app/api/*`**: agent runtime and sessions, stages/scenes/publish, generation (image, video, tts, voice, scene-actions, scene-outlines-stream, agent-profiles), classroom, pbl/v2, comfyui-workflows, export-video, extract-document, parse-pdf, transcription, web-search, provider probes, persistence. These are the course-generation product, not the tutor.

**Verified working, per the repo's own measurement.** `docs/DO-THIS-NEXT.md` states "Current blocking count for a spoken session: **0**. `DATABASE_URL` and the provider keys are set; `/api/tutor/health` says `ok: true`." The live turn model is `google:gemini-3-flash-preview`, measured at 674 ms p50 first token (`docs/KAIZEN-AI-INTEGRATION-PLAN.md:§1.1`). `docs/LOG.md` records the verified runs: 2026-09-05 polish pass — "tsc 0 errors; eslint and prettier clean; tests/tutor + tests/invariants 35 files, 413 passed, 1 expected fail"; 2026-09-04 Wave 1 — "181 files, 19,945 insertions… full suite 7,402 passed / 1 expected fail / 2 load flakes."

**Content.** `lib/tutor/content/item-bank.json` exists (73 KB, 118 item ids): 96 authored items, eight per skill across twelve fractions skills, plus 22 carried from Kaizen-AI's hand-verified seed. Per D29, `reviewed_by` and `reviewed_at` are unset by design — "an item reaches a learner only when a person has read it, and nothing in the repository — pipeline, test, or agent — may stamp its own work," and a test asserts exactly that.

**Exists but unwired or held closed.** Email is unconfigured, and it is the named blocker: without it "a forgotten password cannot be reset, a teen cannot hand an account to a parent, nobody is paged on a safety event, a support message reaches nobody, and no parent hears the weekly report" (`docs/DO-THIS-NEXT.md` §2). Billing is built but gated: the `/welcome` "cancel any time" claim is marked **GATED** in `docs/CLAIMS.md`, "off until `billing_enabled` and the keys (operator item 8)." Under-13 profiles are created **locked** behind `under13_gate`, fail-closed, pending counsel sign-off — `docs/CLAIMS.md` notes the gate's evidence file "`compliance/signoff.md` does not exist." Clerk, Google OAuth and Resend are designed-for but absent (D18). Attention sensing is off by default for teens and adults.

## Dead ends and contradictions

The first row of `docs/DECISIONS.md` explains the origin: "The GitHub repo `saitokiku/KaizenEdu` was empty (one README commit), not a fork of OpenMAIC. OpenMAIC `main` (commit `6334e9a`, v1.0.0 + CVE bumps of 2026-09) was merged in with `--allow-unrelated-histories`." Shared history exists; the remote pointer does not.
2. **`docs/HANDOFF.md` is stale and reads as current.** It is dated 2026-09-04 and states "**The pipeline was never run**, so `lib/tutor/content/item-bank.json` does not exist and there are zero items." 3. **Product identity contradicts the sibling repo's own README.** Kaizen-AI's `README.md:25-27` declares private 1:1 tutoring "Not sold, and not built." This repo *is* a 1:1 tutor, sold first: `docs/MVP-REFERENCE.md` states "**KaizenEdu** … is the AI SaaS being sold first. **Kaizen-AI** … is the old repository: the Austin club, the seats, the human tutors. 4. **The plan's own gates are past.** `docs/PLAN.md` puts Gate 1 (paid beta to the first 20) at 2026-09-17 and Gate 2 at Sep 24–Oct 3, with the YC deadline 2026-11-02. The newest commit in the repository is 2026-09-07, and email — item 2 on the operator list — is still unconfigured.

## Risks

- **Committed secrets: both env files are tracked, and six live-shaped keys are in git history.** `git ls-files` lists `.env` and `.env.local`. `.gitignore:53-57` ignores `.env*` then re-adds `/.env` with the comment "KAIZEN: `.env` holds non-secret product defaults (TUTOR_MODE, model routes) and is tracked" — but `.env.local` is tracked anyway, added by `8a6e46e` "Add ElevenLabs API key to .env.local". `.env` holds 5 variables, all non-secret: `TUTOR_MODE`, `NEXT_PUBLIC_TUTOR_MODE`, `DEFAULT_MODEL`, `MODEL_ROUTES`, `TUTOR_STAFF_EMAILS`. `.env.local` is 525 lines with 124 assignments, of which **25 carry a value; 6 of those are key-shaped**: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GOOGLE_API_KEY`, `TTS_OPENAI_API_KEY`, `TTS_ELEVENLABS_API_KEY`, `ASR_OPENAI_API_KEY`. The other 19 populated entries are `*_BASE_URL` endpoints. No value was read or printed during this index. The repo knows: a `docs/DECISIONS.md` row records "Keys stay committed in `.env.local` on `main` per Manny's instruction… Rotate the keys once they move to Vercel environment variables," and `docs/DO-THIS-NEXT.md` §2 says "rotate them when you have a minute: they were in git history." **They are still there.** The remaining ~99 empty names enumerate every provider upstream supports (Azure, Qwen, DeepSeek, GLM, Doubao, Kimi, MiniMax, Grok, Tencent, Xiaomi, SiliconFlow, OpenRouter, AtlasCloud, Baidu, Bocha, Brave, Exa, Tavily, SearXNG, MinerU, unpdf, AliDocMind, Kling, Seedance, Sora, Veo, HappyHorse, Nano Banana, Seedream).
- **Licence obligations.** Root `package.json` declares **MIT** and `LICENSE` is "MIT License, Copyright (c) 2026 THU-MAIC" — the product ships under upstream's licence and copyright line as the repository stands. Attribution is in `LICENSE`, the site footer and `/legal/credits` (`README.md:5`), which satisfies MIT, but a proprietary product eventually needs its own licence header and a clear separation. Seven `packages/*/LICENSE` files plus three font licences: `OFL.txt`, `ZcoolHappy-LICENSE.txt`, and **`ARPHIC-PL.txt`** (Arphic Public License) — the last is a copyleft-style font licence with redistribution conditions worth counsel's eye if fonts are shipped. **No GPL/AGPL dependency was evidenced**: the six `gpl` matches in `pnpm-lock.yaml` are base64 integrity hashes, and the lockfile carries no licence metadata, so a proper audit needs `pnpm licenses list`.
- **Large binaries.** `assets/` is **82 MB on disk** with 24 tracked files; the largest are upstream demo GIFs — `openclaw-feishu-demo.gif` 18 MB, `python.gif` 14 MB, `avalon.gif` 11 MB, `deepseek.gif` 9 MB, `zhipu-minimax.gif` 7 MB. `.git` is **111 MB**. None of it serves the tutor product.
- **Upstream drift cannot be measured from this clone** (no `upstream` remote). Known baseline: OpenMAIC `main` at `6334e9a`, v1.0.0 plus the CVE bumps of 2026-09, merged 2026-09-04. 509 of 648 commits are upstream's, and the weekly merge the rules require has no configured remote to merge from.
- **Single-provider dependency with an unread terms question.** Every band runs on `google:gemini-3-flash-preview`. `docs/DO-THIS-NEXT.md` §3: a search summary of the Gemini API terms "says the API may not be used in a service directed to, or likely to be accessed by, people under 18; the primary page is blocked from the build sandbox, so nobody here has read it." The fallback is one environment variable.
- **Behavioural coverage is thinner than the test counts suggest.** `docs/HANDOFF.md` §3 records that four of six parallel builders were cut off by an account rate limit, that their unfinished halves are "**unverified beyond the type and lint checks**," and that no builder-authored route tests exist for the product routes. Later runs added tests (413 passing in tutor + invariants), but the product's 7% of the code sits inside a 7,400-test upstream suite.
- **Content gate is a person who has not acted.** Zero of 118 items are signed off, by design; no learner should see the bank until someone reads it.

# Claims matrix

Every public claim Kaizen makes → the code or process that supports it, or a
disposition to fix or remove it.

**The rule:** no claim ships to a user without a row here. A `FIX` or `REMOVE`
disposition must be executed before the surface carrying it goes live.

Verdicts: **TRUE** (code does this) · **FALSE** (code contradicts it) ·
**PARTIAL** (true in some cases, misleading as written) · **GATED** (true in code
but currently switched off, so false to a user today) · **RETIRED** (claim no
longer made / plan no longer sold; row kept for the record).

Verified by direct code and production inspection on 2026-07-28. Two CI guards
enforce a subset automatically: `web/test/claims.test.mjs` (banned phrases) and
`web/test/legalMarkers.test.mjs` (un-cleared legal markers).

# Safety

Scope today: academic integrity + honest limits. The tutor prompt refuses
do-my-homework requests with a warm redirect; uploaded content is treated as
data, never instructions; AI-limitation copy appears on marketing, login, and
legal pages. `safety_events` (admin-only RLS) is the landing table for the next
phase: a fast-model moderation pass on inbound messages flagging concerning
content (self-harm, harassment) → admin review queue → documented escalation
path. Do not market to under-13 users before the COPPA review (see SECURITY.md).

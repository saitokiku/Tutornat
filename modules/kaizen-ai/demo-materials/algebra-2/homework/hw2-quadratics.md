# Answer Key — Homework 2

**Part A**
1. (x − 3)(x − 4) = 0 → **x = 3, x = 4**
2. (x + 5)(x − 3) = 0 → **x = −5, x = 3**
3. (2x + 1)(x − 3) = 0 → **x = −1/2, x = 3**
4. (x − 4)(x + 4) = 0 → **x = 4, x = −4**

**Part B**
5. x² + 8x = −5 → x² + 8x + 16 = 11 → (x + 4)² = 11 → **x = −4 ± √11**
6. x² − 6x = 1 → x² − 6x + 9 = 10 → (x − 3)² = 10 → **x = 3 ± √10**
7. x² − 10x + 25 + 5 = (x − 5)² + 5 → **f(x) = (x − 5)² + 5, vertex (5, 5)**

**Part C**
8. a=3, b=5, c=−2; D = 25 + 24 = 49; x = (−5 ± 7)/6 → **x = 1/3, x = −2**
9. a=1, b=−4, c=2; D = 16 − 8 = 8; x = (4 ± 2√2)/2 = **2 ± √2**
10. D = (−12)² − 4(4)(9) = 144 − 144 = 0 → **one repeated real root** (x = 3/2).

**Part D**
11. x² = −25 → x = ±√(−25) = **±5i**
12. a=1, b=−2, c=5; D = 4 − 20 = −16; √(−16) = 4i; x = (2 ± 4i)/2 = **1 ± 2i**

**Part E**
13. (a) h(0) = **48 feet.**
    (b) −16t² + 32t + 48 = 0 → divide by −16: t² − 2t − 3 = 0 → (t − 3)(t + 1) = 0 → t = 3 or t = −1. The ball hits the ground at **t = 3 seconds** (reject the negative time).

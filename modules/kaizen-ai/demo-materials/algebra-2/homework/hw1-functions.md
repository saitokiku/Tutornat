# Answer Key — Homework 1
*(For the instructor / self-check. Students: try every problem before looking.)*

**Part A**
1. f(3) = 2(9) − 3(3) + 1 = 18 − 9 + 1 = **10**
2. g(−2) = 5 − 4(−2) = 5 + 8 = **13**
3. f(0) = 1; g(0) = 5; sum = **6**
4. f(a + 1) = 2(a + 1)² − 3(a + 1) + 1 = 2(a² + 2a + 1) − 3a − 3 + 1 = **2a² + a**
5. 5 − 4x = 13 → −4x = 8 → **x = −2**

**Part B**
6. All real numbers.
7. All real numbers except **x = 4**.
8. x + 5 ≥ 0 → **x ≥ −5**.
9. x² − 9 = (x−3)(x+3) = 0 at x = ±3 → all reals except **x = 3 and x = −3**.
10. Vertex is the minimum at y = −4, opens up → range **y ≥ −4**.

**Part C**
11. Shift **right 3, up 2**; vertex **(3, 2)**.
12. Shift **left 4, down 1**; vertex **(−4, −1)**.
13. **Reflection across the x-axis** of y = √x; key point stays at (0, 0), curve goes down-right.
14. **y = (x − 5)² − 2**

**Part D**
15. **Not a function.** The input x = 1 is paired with two different outputs (3 and 7); a function requires each input to have exactly one output. The vertical line x = 1 would cross the graph at two points, failing the vertical line test.

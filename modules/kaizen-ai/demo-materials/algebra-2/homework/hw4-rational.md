# Answer Key — Homework 4

**Part A**
1. (x − 3)(x + 3) / [(x + 3)(x + 4)] → **(x − 3)/(x + 4)**, x ≠ −3, −4
2. 2(x² − 4) → 2(x − 2)(x + 2) over (x − 2)² → **2(x + 2)/(x − 2)**, x ≠ 2
3. **2x²/(3y³)**, x, y ≠ 0

**Part B**
4. The (x + 3) cancels → (x² − 1)/(x − 1) = (x − 1)(x + 1)/(x − 1) → **x + 1**, x ≠ 1, −3
5. Multiply by reciprocal: x²/(x² − 4) · (x + 2)/x = x(x + 2)/[(x − 2)(x + 2)] → **x/(x − 2)**, x ≠ 0, ±2

**Part C**
6. Common denom x(x + 1): [3(x + 1) + 5x] / [x(x + 1)] → **(8x + 3)/[x(x + 1)]**
7. x² − 4 = (x − 2)(x + 2). x(x + 2)/[(x−2)(x+2)] − 4/[(x−2)(x+2)] = (x² + 2x − 4)/[(x − 2)(x + 2)] → **(x² + 2x − 4)/(x² − 4)**

**Part D**
8. Multiply by 2x: 2 + x = 6 → **x = 4**
9. Multiply by (x − 3): x = 2(x − 3) + 3 = 2x − 3 → x = 3, but x = 3 is excluded → **no solution**
10. 6/[(x−3)(x+3)] = 1/(x−3) → multiply by (x−3)(x+3): 6 = x + 3 → **x = 3**, excluded → **no solution**

**Part E**
11. 1/6 + 1/4 = 2/12 + 3/12 = 5/12 = 1/t → **t = 12/5 = 2.4 hours** (2 h 24 min).

# Answer Key — Homework 3

**Part A**
1. 2⁴ = 16 → **4**
2. Any base to the 0 power is 1 → **0**
3. 10³ = 1000 → **3**
4. 3⁻² = 1/9 → **−2**

**Part B**
5. **log(xy)**
6. **log(a²/b)**
7. **3·log(x) + log(y) − log(z)**

**Part C**
8. 2ˣ = 2⁵ → **x = 5**
9. 5^(x−1) = 5³ → x − 1 = 3 → **x = 4**
10. x = log(20)/log(3) = 1.3010/0.4771 ≈ **2.73**

**Part D**
11. x = 2⁵ = **32**
12. log[x(x−3)] = 1 → x² − 3x = 10 → x² − 3x − 10 = 0 → (x − 5)(x + 2) = 0 → x = 5 or x = −2; reject x = −2 (log of negative) → **x = 5**

**Part E**
13. (a) A(10) = 2000(1.05)¹⁰ ≈ 2000(1.6289) ≈ **$3,258**. (b) Solve **4000 = 2000(1.05)ᵗ**, i.e. 2 = 1.05ᵗ (t = log 2 / log 1.05 ≈ 14.2 years).
14. (a) The exponent is t/6, so the amount halves every 6 days → **half-life = 6 days**. (b) 18 days = 3 half-lives → 80 → 40 → 20 → **10** (M = 80(1/2)³ = 10).

# Answer Key — Homework 5

**Part A**
1. 27 = 3³, so 27^(1/3) = **3**
2. **⁴√(x³)**
3. **a^(2/5)**
4. 16^(1/4) = 2, then 2³ = **8**

**Part B**
5. √50 = √(25·2) = **5√2**
6. √(48x³) = √(16x²·3x) = **4x√(3x)** (x ≥ 0)
7. ³√54 = ³√(27·2) = **3·³√2**

**Part C**
8. (3 + 5 − 1)√2 = **7√2**
9. √36 = **6**
10. 2² − (√5)² = 4 − 5 = **−1** (difference of squares)

**Part D**
11. Square: x + 4 = 25 → **x = 21** (check: √25 = 5 ✓)
12. Square: 2x − 1 = x² − 4x + 4 → x² − 6x + 5 = 0 → (x − 1)(x − 5) = 0 → x = 1 or 5. Check: x = 1 gives √1 = 1 but x − 2 = −1 ✗ (extraneous); x = 5 gives √9 = 3 = 3 ✓ → **x = 5**
13. Cube: x − 1 = 8 → **x = 9**

**Part E**
14. T = 2π·√(2/9.8) = 2π·√(0.2041) = 2π(0.4518) ≈ **2.84 seconds**

# Answer Key — Final Exam (Units 1–8)

## Section I

1. f(a + 2) = 3(a + 2) − 2 = **3a + 4**.
2. (x + 5)(x − 2) = 0 → **x = −5, x = 2**.
3. √50 = 5√2, √18 = 3√2 → **8√2**.
4. 2⁵ = 32 → **log₂(32) = 5**.
5. D = 4 − 20 = **−16 → two complex conjugate roots** (1 ± 2i).
6. Common difference **d = 3**; a₁₀ = 4 + (10 − 1)(3) = **31**.

## Section II

7. D = 16 + 24 = 40; x = (4 ± 2√10)/4 = **(2 ± √10)/2**.
8. Square: 2x + 3 = x² → x² − 2x − 3 = 0 → (x − 3)(x + 1) = 0 → x = 3 or x = −1. Check: x = −1 gives √1 = 1 ≠ −1 (extraneous). **x = 3** only.
9. (a) P(t) = 500 · 2^(t/3). (b) t = 12 → 2^4 = 16 → 500 · 16 = **8,000 bacteria**.
10. log[x(x − 3)] = 1 → x² − 3x = 10 → x² − 3x − 10 = 0 → (x − 5)(x + 2) = 0 → x = 5 or x = −2. Reject x = −2 (log of negative). **x = 5.**
11. Geometric, a = 3, r = 2, n = 6: S = 3(2⁶ − 1)/(2 − 1) = 3(63) = **189**.
12. (x − 2)(x + 2) / [(x − 2)(x − 3)] = **(x + 2)/(x − 3)**, excluded **x = 2 and x = 3**.
13. (a) 5/12. (b) (4/12)(3/11) = 12/132 = **1/11**.

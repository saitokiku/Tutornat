# Answer Key — Midterm Exam (Units 1–4)

## Section I

1. f(−1) = 1 + 4 + 3 = **8**; f(5) = 25 − 20 + 3 = **8**.
2. x² − x − 6 = (x − 3)(x + 2) = 0 at x = 3, −2 → domain **all reals except x = 3 and x = −2**.
3. (2x − 3)(x + 2) = 0 → **x = 3/2, x = −2**.
4. x² − 8x = −11 → (x − 4)² = 5 → **x = 4 ± √5**.
5. D = 16 − 24 = **−8 → two complex conjugate roots** (no real roots).
6. Shift **left 2, down 5**; vertex **(−2, −5)**.

## Section II

7. D = 36 − 28 = 8; x = (6 ± 2√2)/2 = **3 ± √2**.
8. D = 16 − 80 = −64; √(−64) = 8i; x = (4 ± 8i)/2 = **2 ± 4i**.
9. (a) P(3) = 27 − 36 + 3 + 6 = **0** ✓.
   (b) Synthetic/long division gives P(x) = (x − 3)(x² − x − 2) = **(x − 3)(x − 2)(x + 1)**.
   (c) Zeros: **x = 3, x = 2, x = −1**.
10. Degree **4**, leading coefficient **−2** (negative, even degree) → as x → +∞, q → −∞; as x → −∞, q → −∞. **Both ends point down.**
11. (x − 3)(x + 3) / [(x + 4)(x − 3)] = **(x + 3)/(x + 4)**, excluded values **x = 3 and x = −4**.
12. 1/x = 3/4 − 1/2 = 1/4 → **x = 4**.

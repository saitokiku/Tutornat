# Answer Key — Quiz 2

1. (x − 4)(x − 5) = 0 → **x = 4, x = 5**
2. x² + 4x = 6 → (x + 2)² = 10 → **x = −2 ± √10**
3. D = 9 + 40 = 49; x = (3 ± 7)/4 → **x = 5/2, x = −1**
4. D = 36 − 40 = **−4 → two complex conjugate roots** (no real roots).
5. x² + 2x + 1 − 9 = (x + 1)² − 9 → **f(x) = (x + 1)² − 9, vertex (−1, −9)**

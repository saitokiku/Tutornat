## What each page does
**Learn** (`workspace`): eyebrow `LEARN · <name>`, task title as the page heading, one metadata line (subject · due/past-due · state), instructions as prose; the raw task id / version / origin tag live in a closed "About this task" disclosure. Sample story (reading) rendered as readable prose; K–2 adds the read-together line. Focus panel = the single place to work: not started → one lead sentence + primary Start (K–2: "Tap one big button…" + big "I started"); started → write field + ink "Save step"; K–2 math only → counting tiles (10 big round tiles, "Save count" becomes a step); whole-number sample → answer field + Check with a verdict notice (`match` ok / `no_match` warn / `not_a_number` says "isn't a whole number, so it wasn't checked" — never "wrong", never accepted); then "I'm stuck" / "Mark done" with the self-report line. Side column: Help (sample → Hint / Step-by-step / Voice demo + "scripted sample text — no microphone, no audio, no AI"; custom → one "Ask a grown-up" + "No scripted help exists… nothing is made up"); every requested entry ("Bea asked for a hint") is a separate list item from the scripted reply (rose-ruled, labelled "Scripted sample reply"). Below the focus panel: "What Bea wrote" — verbatim steps with mono timestamps. Parent view: no editing/impersonation; reads the exact work, "Shared record" counts, primary "Write a note about this" → Activity with the task preselected (`link(..,'record',taskId)` sets `ui.recordTask`). Archived: readable history, parent gets Restore, student gets nothing to press. Empty: open-task chooser, or "Nothing to work on yet" → Schoolwork.
**Activity** (`record`): eyebrow `ACTIVITY · <name>`, selected task as heading (or "All tasks for …"), `Show` task filter (archived tasks suffixed), chronological timeline grouped by day; each event names who/what in family words ("Bea wrote", "Bea asked for a hint", "Scripted sample reply", "Scripted check: answer “225 stickers” — not a whole number, not checked", "Parent note"); student steps and parent notes are verbatim paragraphs; multi-task view adds the task title. Parent side: "Note for Bea" composer tied to the selected task (archived → "notes are still allowed; work can't be added until restored"); student side: "What your parent can see". Mastery / cadence / memory-only provenance sit in a closed "How this record works" disclosure, not as banners. Empty: "Nothing recorded for Cal yet" → Schoolwork. No percentages, grades or invented numbers anywhere (asserted).

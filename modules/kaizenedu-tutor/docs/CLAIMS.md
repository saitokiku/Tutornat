# Claims ledger

One row per sentence a stranger could hold us to (claims-discipline skill). A claim ships only with a row that names the code, test, measurement or record making it true. Recounted 2026-09-30 (D36): **38 rows** — 30 TRUE, 6 RETIRED, 2 Do not claim.

Verdicts: **TRUE** (code does this; the evidence column names it) · **FALSE** (code contradicts it; fixed or removed before the surface ships) · **PARTIAL** (true in some cases, misleading as written; reworded) · **GATED** (true in code but switched off today; the surface says so) · **RETIRED** (no longer made; row kept) · **Do not claim** (banned until a named gate clears).

The scanner (`tests/invariants/claims.test.ts`) rejects the banned forms on every surface below, refuses a typed price where `PLAN` should be interpolated, refuses any legal-entity name until `LEGAL_ENTITY` exists, and refuses drafting markers. A pattern that fires on a true sentence gets a row here and an allowlist entry in the test that cites the row, never a wider regex.

## Numbers on a page

A number a parent sees is a value computed for that account, a limit from `PLAN` or `COST`, or a measurement with a file under `docs/metrics/`. `README.md` quotes the learner and staff ceilings from `COST` and `STAFF`; `docs/DO-THIS-NEXT.md` quotes one registrar's domain price, dated, which is not a product price and is allowlisted in the test by name.

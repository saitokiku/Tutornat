# Consolidation: four repositories, one product

**Written 2026-09-30** by the docs seat, from the code in this repository, `docs/GUEST-MODE.md`, decision D35, and the six structured reads of the four repositories taken the same day. It is the record of what was folded into KaizenEdu, what was not, and what comes next. Where it names a file it names a real one; where it names an idea that is not yet in the code it says so.

## 1. The goal and the base

The owner's direction on 2026-09-30 was to take the best ideas of the four repositories (`KaizenEdu`, `Kaizen-AI`, `trellis`, `Tutornat`) and ship them as one product: a free tutor, no account, for any subject and any age from early childhood to adult, with grades 4 to 9 as the first focus; accounts and billing set aside for later. KaizenEdu (working name Natural Tutor) was chosen as the base because it already had the parts that are hard to build and slow to verify: the voice-first turn loop with barge-in, the whiteboard the tutor draws on while it talks, tutor-authored and bank checks graded by code first and a model second, the append-only evidence record with its estimate and confirmed tiers, the safety screen and paging, the cost ceilings and kill switch, the five CI invariants, and a live deployment at kaizenedu.net. Kaizen-AI's durable value is its engine's pedagogy, not its product; trellis's durable value is the clearest statement of the honest-record rules; Tutornat holds nothing. Folding the ideas into KaizenEdu meant a handful of additive modules behind the same cookie and the same invariants, which is what landed (section 3).
